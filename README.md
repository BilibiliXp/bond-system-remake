# 三国自走棋商店 Demo 说明

## Demo 目标

本 Demo 只搭建网页框架和商店阶段的基础循环，用于后续继续填充真实武将、装备、计策、缘分和战斗内容。

当前实现范围：

- 展示商店阶段 HUD：回合、阶段、商店阶级、金币、生命、奖杯。
- 展示 6 个商店槽位。
- 展示 5 个己方阵容槽位。
- 支持刷新商店、拖拽购买武将、结算计策占位卡、出售阵容武将。
- 支持“商店 -> 战斗 -> 下一回合商店”的循环。
- 战斗阶段暂时省略，结束回合后短暂停留并自动跳过。

当前不实现：

- 真实三国卡牌设计。
- 真实战斗模拟与战斗表现。
- 缘分计算。
- 装备系统、计策目标选择、合并、升级奖励和挤位奖励入店。
- 主菜单、模式选择、卡包选择、结算和游戏结束页。

## 运行方式

直接用浏览器打开 `index.html` 即可运行。

## 商店阶段基础规则

规则参考 `D:\三国自走棋\docs_ai` 中的商店系统与游戏循环文档，本 Demo 只取最小可演示子集。

### 回合与金币

- 第 1 回合从商店阶段开始。
- 每回合进入商店阶段时获得 100 金币。
- 金币不跨回合保留。
- 点击结束回合后，当前金币清零。
- 金币上限为 100，本 Demo 已在出售收益处保留上限判断。

### 商店槽位

Demo 商店固定为 6 个槽位：

| 槽位 | 用途 | Demo 状态 |
| --- | --- | --- |
| 1-4 | 武将刷新区 | 固定生成武将占位卡 |
| 5-6 | 计策刷新区 | 固定生成计策占位卡 |

商店刷新规则不会随回合推进改变，始终保持 4 个武将和 2 个计策。

### 刷新

- 刷新商店消耗 1 金币。
- 金币不足时不能刷新。
- 刷新会替换当前商店卡。
- 剩余槽位补齐到 4 个武将和 2 个计策。

### 购买

- 武将占位卡固定消耗 3 金币。
- 计策占位卡按当前占位数据消耗金币。
- 金币不足时购买失败。
- 购买武将时，需要将商店里的武将卡拖拽到空阵容槽。
- 阵容已满时购买武将失败，不替换已有单位。
- 购买计策时，本 Demo 暂以“支付费用并清除商店槽位”表示结算完成。

### 阵容与出售

- 己方阵容固定 5 个槽位。
- 当前 Demo 没有备战区。
- 出售只在商店阶段进行。
- 出售收益按武将等级计算，当前占位武将均为 1 级，因此出售获得 1 金币。

### 商店到战斗循环

当前 Demo 的阶段循环为：

```text
商店阶段 -> 点击结束回合 -> 金币清零 -> 战斗阶段占位 -> 自动跳过 -> 下一回合商店阶段
```

战斗阶段只保留状态切换，不计算胜负、不修改生命和奖杯。
